# Work items

One dated Markdown file per coherent task. Start with [TEMPLATE.md](TEMPLATE.md), update it throughout the work, and link it in the PR. Search this directory by subsystem, decision, or related task before beginning. There is no central registry to keep in sync: filenames and Git history provide the index.

Required metadata: `Status` (`planned`, `in-progress`, `in-review`, `blocked`, `done`, or `superseded`), `Owner`, `Source`, and `Branch`. Required sections are shown in the template. Use concrete content instead of angle-bracket placeholders. Keep historical records; link corrections and superseding work instead of deleting them.
